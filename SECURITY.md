# Security Policy

> 🇫🇷 Pour signaler une faille de sécurité, n'ouvrez pas d'issue publique : utilisez le signalement privé décrit ci-dessous (en français ou en anglais).

## Supported versions

| Version | Supported |
|---|---|
| 1.0 (latest release) | ✅ |
| Older or self-built APKs | ❌ — please update to the [latest release](https://github.com/Furycom/proxy-android/releases/latest) first |

## Reporting a vulnerability

**Please do not report security problems in public issues or discussions.**

Report them privately through GitHub instead:

1. Go to the [**Security** tab](https://github.com/Furycom/proxy-android/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and the phone and Android version you used.

Only the maintainer can see your report. You can expect a first answer within about a week. Once a fix is released, you will be credited in the release notes if you wish.

## Scope

Things we especially want to hear about:

- any way the app could send data off the phone, or be made to;
- any way another app on the phone could control the device through Proxy;
- any command the app could send that changes the device's firmware, heater tuning or factory settings — the app is designed to never do this;
- problems with the published APK or its signature.

Problems in the device itself or in the official app are out of scope: please report those to their manufacturer.
